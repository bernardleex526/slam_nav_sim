## 诊断与修复

1. **位姿漂移。** 默认 RMHC 在此输入上的校正不足，轨迹虽然在刚体对齐后 ATE 达标，仍留下相对于初始世界坐标的累计旋转和位置偏差。单独修改随机搜索范围、关闭运动补偿或调整半格原点均不能让原地图通过。现在默认使用本项目实现的点到线局部配准：仅以当前扫描、轮速先验和历史估计扫描子地图作为输入。参考轨迹和参考地图仍只进入评估函数。旧 RMHC 仍可通过 `configs/local-rmhc.yaml` 重现失败。
2. **额外射线侵蚀墙边。** 原地图积分使用 native scan 的 span=3，将一个测得距离扩展到三个不同角度，可能在深度突变附近生成实际未观测的清空射线。改为 span=1，使建图射线角度与输入束一一对应。地图质量参数仍是 50，hole width 仍是 600 mm，没有扩大障碍宽度来通过评分。
3. **灰度换算不一致。** 旧适配器直接使用灰度 65／196 分类，与 YAML 声明的占据概率 0.65／空闲概率 0.196 不一致。现按 `(255-gray)/255` 计算概率，再使用原声明值分类。YAML 概率门槛未改，导出的栅格值因此得到正确解释。
4. **半格偏移。** native 栅格索引对应像素中心，ROS 地图原点对应栅格左下角。现原点减去半个分辨率，即 0.02 米，并对初始旋转同时转换轨迹和地图原点。
5. **输入与回退边界。** 定位和建图使用相同的边缘束排除区间，法线估计也不能引用被排除的邻束。匹配中途失去对应关系时回退到轮速、标记证据不足并禁止插入新关键帧。NaN、负无穷及越界读数被跳过；只有显式正无穷无返回值会清空到量程上限，有限最大量程读数仍作为测得端点。

诊断中的“固定已知位姿”实验仅用于隔离栅格积分问题，未进入正式算法、最终结果或验收路径。正式适配器的函数输入不包含真值或参考地图。

## 适用边界

本地默认位姿估计器已从纯 RMHC 改为自建局部配准，地图积分仍复用 BreezySLAM。该配准是确定性的，改变 RMHC 随机种子不会改变它；因此额外使用传感器噪声种子对照，而不是把重复相同计算当作随机鲁棒性证据。

目前只覆盖固定二维世界及其噪声变化，不代表新世界泛化、全局回环诊断或盲测通过。新本地适配器要求瞬时／已去畸变扫描；束间时间非零时明确拒绝，交由 ROS 后端或先行去畸变处理。公开真实日志缺少独立真值，依然不宣布精度通过。ROS 2／Gazebo 镜像构建、Nav2 闭环导航、三维与真机验收均保持待执行。
